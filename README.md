# Week Kitchen

Home Assistant app (add-on): a weekly meal plan, recipe box, shopping list and step-by-step
cook mode, stored as JSON files in a folder you choose. See [DOCS](week_kitchen/DOCS.md).

Add `https://github.com/mbwp1234/week-kitchen` under **Settings → Apps → App store → ⋮ → Repositories**.

No personal data lives in this repository; it all lives in the app's `data_dir`.

`node test/smoke.mjs` runs the API tests.
